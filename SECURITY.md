# Security Policy

Plume records audio and makes transcripts, so privacy and security matter. Thank you for reporting problems responsibly.

## Reporting a problem privately

Please **don't** open a public issue for a security or privacy problem. Report it in one of these ways:

1. **Preferred:** use GitHub's private reporting at <https://github.com/vikramgulia/plume/security/advisories/new>.
2. **Email:** contact@vikramgulia.com, with "Plume security" in the subject.

Please include:
- what you found and where (the version, macOS version, and the steps to reproduce it)
- what an attacker could do with it
- any proof of concept, if you have one

## What to expect

- I'll acknowledge your report within a few days.
- I'll investigate, keep you updated, and fix confirmed problems in a new release as soon as I reasonably can.
- With your permission, I'll credit you in the release notes once a fix is out.
- Please give me time to fix the problem before you share details publicly.

## Supported versions

Only the latest release of Plume receives security fixes. Download it from the [Releases page](https://github.com/vikramgulia/plume/releases/latest).

## What counts

Examples that matter for Plume: recordings, transcripts or voice profiles leaving the Mac without the user's consent; files being read or written outside the chosen folders; a way to make the app record without the user knowing; problems in the signing, update or release process.
